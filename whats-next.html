What's next

More support for teachers, with quality checks before release.

Next, we want to make answers clearer, improve replies in each language and keep testing marking tools. These plans do not promise a release date.

Available now

Features available now

  • Typed questions about school topics.
  • Voice input through the phone's listening and speaking tools.
  • A choice to hear replies aloud and stop them when needed.
  • Quiet mode.
  • Hindi, Marathi and English reply settings.
  • Teacher profile saved on the phone.
  • Reminder to check the answer.
  • One-question-at-a-time interaction.

A new screen design is also being tested. Ask which design is included in the version you try.

Turned off in the regular app

Built but turned off

Using textbook facts to write replies

Finding the right topic was tested. But adding textbook facts did not improve the replies enough, so this feature stays turned off.

Suggested marks

A tool for checking typed answers is being tested with marking guides. It is not reliable enough yet and cannot be used in the regular app.

Planned · Not currently available

Planned or still being worked on

Better language and answer quality

Reduce unclear replies and improve performance across teaching topics, especially in Marathi.

Voice supplied inside the app

Add the app's own listening and speaking tools so voice can work without relying on the phone's separate tools.

Suggested marks that teachers can check

Once the tool is reliable enough, it may suggest marks and show the words in a student's typed answer that support them. The teacher would still decide the final marks.

Reading handwritten answers

Try this again only when handwritten answers can be read reliably without internet. It is not available now.

Class study reports

Work on reports that help teachers see which topics need more attention. A ready-to-use reporting service is not available yet.

More phone tests and accessibility checks

Try low-cost phones and check tools that read the screen aloud. Test the settings teachers actually use.

Closing note: Ask about the current version before planning around any future feature.

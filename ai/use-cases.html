VIDYA Copilot: use-case summary

SituationProduct actionResult and check
Before a lesson, revisiting a familiar conceptAsk one standalone question, typed or spokenA first response to check against the textbook and notes
Between classes, a short questionInclude class, topic and detail in one questionReply to read or hear; no long chat needed
Quiet staffroomSwitch "Speak replies aloud" offRead quietly without disturbing colleagues
Hands busy, listening preferredSwitch speech on; stop it when neededSpoken reply via the phone's speaking tool; subject to phone services
Marathi- or Hindi-medium teachingSet reply language explicitly or match the questionReply in the chosen language; check clarity and script; Marathi needs more work

By visitor type

VisitorLikely questionHonest answer
Classroom teacherWill it help with the small questions in my day?Yes, one question at a time, with the teacher checking each reply
Marathi-medium teacherCan I use the language I prefer?Marathi is available; reported tests found it needed the most improvement
Academic coordinatorCan we trust replies before using them?Treat every reply as a draft; the memory warning is on every reply; marking is off
Principal or school leaderCan we try it carefully?Yes: few teachers, known topics, real phones, teachers checking replies, decide from findings

Not a use case today

  • Marking answer papers (turned off).
  • Reading handwritten papers (not available).
  • Class study reports or a school dashboard (planned).
  • Textbook-grounded answers (turned off).
  • Student use (separate VIDYA AI app).
